# GitHub Pages Deployment Demo 🚀

This is a complete project demonstrating how to deploy a beautiful, dynamic, glassmorphism-styled static website to **GitHub Pages** using **GitHub Actions**.

## How to Deploy to GitHub Pages

1. **Create a new repository** on GitHub.
2. **Push the contents of this folder** (including the `.github` directory) to the `main` branch of your new repository.
3. In your GitHub repository settings:
   - Go to **Settings > Pages**
   - Under **Build and deployment**, ensure the **Source** is set to **GitHub Actions**.
4. The deployment will start automatically! You can track the progress in the **Actions** tab of your repository.
5. Once complete, your site will be available at `https://<your-username>.github.io/<your-repo-name>/`.

## Features
- **Modern UI**: Dark mode, gradients, micro-interactions, and glassmorphism.
- **Zero Config**: No build step needed; it's pure HTML, CSS, and JS.
- **Automated Deploy**: Includes a pre-configured `.github/workflows/deploy.yml` using the latest official actions from GitHub.

Enjoy your deployed site!
